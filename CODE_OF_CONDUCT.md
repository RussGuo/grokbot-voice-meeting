# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1.

We want a welcoming place to build voice meetings. Harassment, personal attacks, and publishing other people's private information are not acceptable. That includes meeting recordings, join tokens, and bot context that someone shared for a test.

## Reporting

Report conduct issues through the process in [SECURITY.md](SECURITY.md) if they also involve a secret, or open a private security advisory on GitHub. Maintainers will respond as they can. This repository may not have a paid staff.

## Scope

This applies to issues, pull requests, and any space that represents this project.
